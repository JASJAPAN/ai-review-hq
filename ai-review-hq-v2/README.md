# AI口コミアンケート 本部共通システム v2

複数店舗のご来店アンケートを1つのシステムで運用し、AIが口コミ文の下書きを作成、
星の数に応じて **Google口コミへの誘導** と **自社完結（改善ヒアリング）** に分岐します。

```
お客様の流れ（卓上QR → スマホ）
  Step1 星を選択
  Step2 評価ポイントをタップ（店舗ごとに設定可）＋自由記述（任意）
  Step3 「AIで簡単に自動作成」→ 文章を確認・編集 → 登録
    ├ しきい値以上（初期値★4）→ 文章を自動コピー → Google口コミ画面へ
    └ しきい値未満            → 自社で完結。改善要望をヒアリングして終了
```

## 主な機能

- 店舗別URL `/s/<slug>` と本部管理画面 `/admin`
- AI生成：`ANTHROPIC_API_KEY` → `OPENAI_API_KEY` → ローカル生成 の順で自動選択。
  APIキーなしでもデモ運用できます
- 生成文は「入力された事実のみ使用・毎回文体を変える・広告調禁止」を指示。
  お客様が編集してから登録する前提の設計です
- 店舗ごとの設定：評価ポイント（最大12個）、誘導しきい値、誘導モード、あいさつ文
- 本部ダッシュボード：総回答・平均・星の分布・評価ポイントランキング・
  店舗別比較（回答数／直近7日／Google誘導・クリック／低評価件数）
- 店舗詳細：回答一覧（★3以下フィルタ・★2以下は行を強調）、改善要望の表示、
  QRコードPNG出力、CSV出力（Excel対応BOM付き）
- 生成APIのレート制限（IPごと10回/分）、タグのホワイトリスト検証、入力長制限

## ローカルで起動

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # 値を編集
export ADMIN_PASSWORD='任意のパスワード'
python app.py
```

- お客様画面: http://localhost:5000/s/nansatsu （初期データ：南薩農場・川畜 天文館店）
- 本部画面:   http://localhost:5000/admin

## 本番公開（Render想定）

`render.yaml` 同梱。環境変数に `ADMIN_PASSWORD` / `SECRET_KEY` / `ANTHROPIC_API_KEY` /
`BASE_URL`（公開ドメイン。QRに埋め込まれます）を設定してください。
SQLiteは永続ディスク（`DATABASE_PATH=/var/data/reviews.db`）に置きます。
店舗数・回答数が増えたらPostgreSQLへの移行を推奨します。

## 運用手順

1. `/admin` にログインし「店舗を追加」。Googleビジネスプロフィールの
   「クチコミを増やす」から取得した投稿用リンクを登録
2. 店舗詳細で評価ポイントを業態に合わせて編集（焼肉店なら「お肉がおいしい」等）
3. QRコードをダウンロードし、卓上POP・レジ横・会計伝票に設置
4. 本部は週1回ダッシュボードを確認。低評価（★2以下）は店舗詳細の改善要望を
   店長へ共有し、CSVで月次集計

## 重要：規約・法令上の注意

- **Googleの口コミポリシーは「高評価の人だけに投稿を促す」運用（レビューゲーティング）を
  禁止**しています。違反が検出されると口コミの削除やプロフィールの制限を受ける可能性が
  あります。本システムは要件どおり分岐機能を実装していますが、店舗設定の誘導モードで
  **「全員に誘導」** を選べばこのリスクを回避できます（低評価の改善ヒアリングは
  どちらのモードでも取得できます）。
- 景品表示法のステルスマーケティング規制の観点からも、**投稿するかどうか・内容・星の数は
  お客様自身の判断**である旨を画面に明記し、AI文は「本人が確認・編集する下書き」として
  扱う設計にしています。投稿の対価（割引・特典）を条件にしないでください。
- コンサル先へ提供する場合は、上記リスクの説明と誘導モードの選択を先方に委ねる運用を
  推奨します。
